# BILDR governed self-improvement implementation plan

**Status:** dependency-ordered implementation plan

The program is intentionally staged so BILDR can observe and evaluate itself
before it may propose or promote a persistent change.

1. [Program boundaries and observation](self-improvement/implementation/01-boundaries-observation.md)
2. [Evaluation and learning](self-improvement/implementation/02-evaluation-learning.md)
3. [Experiments and promotion](self-improvement/implementation/03-experiments-promotion.md)
4. [Extensions, pilot ladder, and acceptance](self-improvement/implementation/04-extensions-pilots.md)

No stage may use later-stage capabilities to excuse missing evidence in an
earlier foundation. The first production milestone is observe-only.
